as green mass. They are generated by this repository, not taken from a pack,
so they carry the repository's own licence.

## How they are made

`tools/vegetation/build.py`, with Blender's Python module (`bpy` 5.2.2),
builds every model from a fixed seed, so the same script gives the same bytes.

- Crowns and bushes are lumpy icospheres, flat shaded, so they read as leaves
  rather than balls; a spruce is three stacked cones.
- Each model is one static mesh, metre-scale, Y-up, standing on y = 0 at the
  origin. They carry no rig and no clip: vegetation is drawn by the thousand,
  instanced, and a still crown is the cheap one.
- Colours: leaves `#b9dca8`, `#9fcd8f`, `#86b97a`; needles `#7fae86`; bark
  `#a99a88`.

## Where they may stand

Nothing places them yet. The basemap archive carries no tree points, and
`docs/map-data.md` decides that individual street trees are never drawn at
made-up coordinates. Where these models may stand is decided with the layer
that draws them, against that rule.
