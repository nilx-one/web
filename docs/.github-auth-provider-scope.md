# GitHub browser authentication boundary

GitHub is an identity-only browser authentication provider in this slice.

- GitHub proves a stable numeric external account subject.
- 0x1 remains the authority for Bond identity, native credentials, sessions, and registration.
- The OAuth authorization request does not ask for repository scopes.
- The callback uses the short-lived provider token only to resolve `/user`; the token is not persisted.
- A successful GitHub sign-in grants no repository capability to the resulting 0x1 session.
- GitHub App installation, repository evidence, Mind discovery, Mind selection, and Mind bootstrap are outside this slice.
- Provider/settings presentation for GitHub is intentionally deferred to the next provider-connections slice.

This boundary keeps authentication independent from future GitHub repository evidence and Mind integration.
